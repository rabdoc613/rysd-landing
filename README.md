# RySD Consulting LLC — Web Production Repository

Production repository for the canonical digital business card and executive portal for **Ryan Dulkin, Ph.D.** (`rysdconsulting.com`).

## Architecture & Governance
* **Asset Type:** Zero-dependency, single-page static executive portal.
* **Hosting:** GitHub Pages via custom apex domain (`rysdconsulting.com`).
* **Design Tokens:** Deep obsidian-violet palette (`#0a0614` / `#120a24`), electric teal circuit telemetry accents (`#00e5ff`), and RySD brand violet (`#9d4edd`).
* **Typography:** `Inter` (sans-serif) and `JetBrains Mono` (telemetry/data).
* **Compliance Standards:** Formally cleared per RySD Governance Credibility Zones (`[GREEN]`). Adheres to plain-English operational metrics and human-in-the-loop (HITL) system standards.

## Deployment Protocol
1. Static code updates are committed to the `main` branch.
2. GitHub Pages serves directly from `/root` on `main`.
3. Apex DNS managed via Google Workspace / DNS CNAME record mapping.
